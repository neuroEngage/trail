# F1 — Connect data
## Goal
Bring data in from files and PostgreSQL as immutable snapshots without ever modifying the source.
## Depends on
F0.
## Inputs / Outputs
`POST /sources/files`, `POST /sources/databases`, `POST /sources/{id}/test`, `GET /sources/{id}/schemas`, `POST /sources/{id}/snapshot`, `PATCH|DELETE /sources/{id}`, `POST /sources/{id}/refresh`.
## User flow
**A. File:** Upload from device -> Validate (type, size, encoding) -> Parse -> Preview -> Register dataset.
**B. Database:** Choose database -> Pick connector (PostgreSQL first; MySQL, SQL Server, cloud storage later) -> Enter read-only credentials -> Test connection -> Discover schemas -> Select table or query -> Preview -> Snapshot & register.
**C. Manage:** Edit, refresh or disconnect a saved source.
## Business rules
- Formats: CSV, Excel, Parquet, JSON, PostgreSQL.
- Credentials encrypted at rest (D8); never logged; never returned by the API.
- Reject writable DB users with a clear warning (check privileges) or enforce a read-only transaction.
- Connector interface is abstract so MySQL/SQL Server can drop in later.
- Refresh creates a NEW snapshot version; it never overwrites.
## Out of scope
MySQL, SQL Server, cloud storage connectors; scheduling; profiling.
## Acceptance criteria
1. Each supported file format uploads, parses and previews correctly.
2. Corrupt, empty, wrong-type and oversized (>500 MB) files are rejected with readable errors.
3. UTF-8, Latin-1 and UTF-16 CSVs are detected and parsed.
4. Wrong credentials / unreachable host give a clear, distinct error.
5. Source DB checksum (table hash) is identical before and after snapshot.
6. Credentials are not readable in DB rows or logs (test greps both).
7. Disconnect removes the source but keeps existing snapshots (documented).
8. Audit events written for create/edit/refresh/disconnect.
## Tests required
Unit (validators, encoding detection), integration (real Postgres from compose), golden (`golden_clean.csv` row count == 1000), edge (`testdata/edge/*`), security (credential leak test, read-only user cannot write).
