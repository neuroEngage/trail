# F8 — Report
## Goal
Generate a reproducible, audit-ready report of the dataset's quality journey.
## Depends on
F1-F7.
## Inputs / Outputs
`POST /reports` (job), `GET /reports/{id}/download`, `POST /reports/{id}/share`.
## User flow
Choose dataset and versions -> Select sections -> Generate -> Download PDF / HTML / Excel, or share link.
## Sections
Profile, issues, actions taken (from audit log), before/after comparison, open issues.
## Business rules
- Numbers must equal the live screens.
- Regenerating the same inputs gives identical content (timestamp excluded or fixed).
- Share links are tokenised, expire (default 7 days) and respect permissions.
## Out of scope
Scheduled/emailed reports, custom branding.
## Acceptance criteria
1. Each section's numbers match the API responses for the same versions.
2. PDF, HTML and Excel all generate and open.
3. Regeneration is reproducible (content hash equal).
4. Expired or revoked share link returns 410/403.
5. Report generation is audited.
## Tests required
Integration (numbers vs API), reproducibility, security review (share link), UI.
