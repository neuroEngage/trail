# F2 — Discover & preview
## Goal
Give a catalogue view of what is in a dataset before any analysis.
## Depends on
F1.
## Inputs / Outputs
`GET /datasets`, `GET /datasets/{id}`, `GET /datasets/{id}/versions`, `GET /versions/{id}/columns`, `GET /versions/{id}/rows`.
## User flow
Open dataset -> Browse schemas, tables, columns -> Preview rows -> View metadata (size, rows, types, source, owner).
## Business rules
Read-only. Pagination is server-side. Respect ownership/role permissions.
## Out of scope
Profiling stats, quality scoring, editing.
## Acceptance criteria
1. Metadata (rows, columns, types, size, source, owner) matches the real file/table.
2. Row preview is paginated and sortable by column order; a 1M-row version loads page 1 in < 2 s.
3. Column list shows inferred type.
4. A user without access gets 403.
5. Empty dataset shows an empty state, not an error.
## Tests required
Unit (pagination), integration (metadata vs source), performance (1M rows), UI (loading/empty/error).
